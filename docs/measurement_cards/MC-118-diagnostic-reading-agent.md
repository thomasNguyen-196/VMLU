# MC-118 — DSHF, OMPF, OMPS and the direct arms C and O for Qwen3.5-9B (IEC) and MiMo-V2.6-Flash (OpenCode Go) on the 400 Reading-400 items, the agent finding each passage in a long-file reading corpus, two draws: do the legal-agent findings hold on general reading?

Registered 2026-11-25 (+07), before any benchmark-item request of this card. The design is in `openspec/changes/diagnostic-reading-agent`. On 2026-11-25 the owner made these choices:
- **The question.** The legal-agent experiment on another field, with OMPS ("lên plan cho phần thực nghiệm với harness giống phần luật đi (bao gồm đổi system prompt của omp thành dsh luôn)").
- **The layout.** Long files like the law corpus ("File dài, giống luật").
- **The scoring.** Gold-token recall registered, with a judge on a sample ("R chính + giám khảo trên mẫu").
- **The design** ("duyệt").
- **One sentence per line** ("Mỗi câu một dòng"), after the paging check.
- **The smoke test** ("okay").
- **Qwen's direct route** ("Thử lại, lỗi nữa thì đổi route").

This card does not change MC-90 to MC-117: their registered text, manifests, rules, analyses and conclusions stand. Their modules are imported, not edited. No shared code changes: `diagnostic_prospective.ARMS` already holds every arm id used here.
