# MC-90 — Qwen3.5-9B-65K (IEC), diagnostic prospective wide: B and S on the 1,239 non-anchor items

Registered 2026-10-22 (+07) before benchmark-item requests. Only synthetic prompts have reached the endpoint so far (2 pings, 24 timing probes and 144 prompt-development requests; none is a benchmark item). The project owner approved the plan and its defaults on 2026-10-22; the design is `openspec/changes/diagnostic-prospective-campaign` and this card is the wide companion of a later core card, which waits for the completed pilot audit.

| Scoring | B: frozen V1 scorers on the raw response. S: score from the text after the last final-answer label (`diagnostic-final-segment-v1`); a multiple-choice response without the label is unparsed and the first-match parser is not applied to the whole response; reading uses the frozen last-label extraction. Unparsed answers stay in denominators; format compliance is reported separately. Reading correctness is exact match; token-F1 >= 0.8 with exact match 0 is a semantic-audit candidate only. |
| Gates | Execution requires this card heading in `measurement_card.md`, the registration record with matching hashes, and endpoint host and model equal to this card. `inference_ready` is not required because no audit anchor is touched. |
| Analysis | Fixed before data (`analysis` in the campaign protocol): single-attempt item outcome, rescue and regression versus B inside the multiple-choice and reading families, exact two-sided McNemar with Holm correction, Wilson intervals for recovery and regression, passage-cluster bootstrap (2,000 resamples, seed 42) for net gain. Secondary and labelled as such: compliant-only sensitivity, paired token-F1 difference and a format-suspect flag on reading rescues. Before any effect is read, a parity gate requires B per dataset to lie inside the MC-83 interval (Legal MC 76.70-88.70, Legal NLI 85.74-94.87, Vi-SQuAD EM 69.59-81.50, Vi-DROP EM 41.09-55.05, ViBidLQA EM 24.05-31.58). With one draw per arm there is no B-versus-B noise reference and no oracle-routing ceiling is read as headroom. The multiple-choice family has about thirty B-incorrect items, so a null result there is reported as insufficient power. Per-dataset results are descriptive only. |
